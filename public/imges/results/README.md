# Фото «до» и «после»

Положите файлы сюда и пропишите пути в `src/entities/result/model/data.ts`:

- `case-knee-before.jpg` / `case-knee-after.jpg`
- `case-foot-before.jpg` / `case-foot-after.jpg`
- `case-hip-before.jpg` / `case-hip-after.jpg`

Пример в data.ts:

```ts
beforeSrc: "/results/case-knee-before.jpg",
afterSrc: "/results/case-knee-after.jpg",
```
